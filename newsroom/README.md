# 📰 חדר החדשות

מערכת חדשות והתראות אישית לשוק ההון האמריקאי. רצה לבד ב-GitHub Actions, בלי שרת ובלי עלות.

> **שלב 1 (הנוכחי):** איסוף נתונים, בוט טלגרם ומהדורת בוקר.
> שלב 2: התראות חכמות · שלב 3: דשבורד · שלב 4: שאר המהדורות וליטוש.

---

## איך זה עובד, בקצרה

```
GitHub Actions (כל שעה + לפני 07:00)
   └─► python -m newsroom tick
         1. קורא פקודות מהבוט (/add, /remove ...)
         2. בודק אם מגיעה עכשיו מהדורה (לפי שעון ישראל, עם מעברי שעון וחגים)
         3. אוסף: Finnhub · Tiingo · FRED · SEC · Fed · CoinGecko · RSS
         4. מקבץ כותרות לסיפורים, מחשב תנועה חריגה לכל מניה
         5. Gemini כותב רק את המשפטים. המספרים מגיעים מהקוד.
         6. בודק שכל מספר בטקסט קיים בנתונים. משפט עם מספר מומצא נמחק.
         7. שולח לטלגרם
   └─► שומר מצב בענף data
```

**למה זה אמין:**
- **הרצה שהתעכבה או לא רצה:** ההרצה הבאה תופסת אותה. המהדורה "מגיעה" מ-06:55 ועד 12:00, כל עוד לא נשלחה היום.
- **מקור שנפל:** המהדורה יוצאת בלעדיו, ובתחתית כתוב "⚠️ מקורות שלא ענו".
- **מודל השפה נפל:** יוצאת מהדורת גיבוי מתבנית, עם מספרים וכותרות בלבד.
- **הרצה שלמה נכשלה:** מגיעה הודעת "⚠️ המערכת נתקלה בתקלה" בטלגרם.
- **GitHub הפסיק להריץ בכלל:** healthchecks.io (אופציונלי, ראה שלב 7) שולח התראה.

## 🛠 הגדרה ראשונה, צעד אחר צעד

### שלב 1: בוט טלגרם (5 דקות)
1. בטלגרם, חפש **@BotFather** (עם וי כחול) ולחץ **Start**.
2. שלח `/newbot`.
3. כתוב שם לתצוגה, למשל `חדר החדשות`.
4. כתוב שם משתמש שמסתיים ב-`bot`, למשל `jonathan_newsroom_bot`.
5. BotFather ישלח **טוקן** שנראה כך: `1234567890:AAH...`. שמור אותו, זה הסוד הראשון.
6. לחץ על הקישור לבוט החדש, לחץ **Start**, ושלח לו `שלום`. זה נחוץ כדי שנוכל לגלות את ה-chat_id שלך.

### שלב 2: מפתחות API (כולם חינמיים, בלי כרטיס אשראי)

| שירות | איפה | מה לעשות |
|---|---|---|
| **Finnhub** | finnhub.io | **Get free API key** ← הרשמה ← המפתח מופיע ב-Dashboard |
| **Tiingo** | tiingo.com | **Sign Up** ← אישור במייל ← בתפריט: **Account → API → Token** |
| **FRED** | fredaccount.stlouisfed.org | יצירת חשבון ← **API Keys** ← **Request API Key** ← כתוב "personal research" |
| **CoinGecko** | coingecko.com/en/api/pricing | תחת **Demo**: **Create Free Account** ← **Developer Dashboard** ← **Add New Key** |
| **Gemini** | aistudio.google.com | התחברות עם חשבון Google ← **Get API key** ← **Create API key** |

> 💡 ב-Gemini, בעמוד **Rate limits** של AI Studio רואים את המכסה החינמית העדכנית לכל מודל.

### שלב 3: שמירת הסודות ב-GitHub
1. ב-GitHub, פתח את ה-repo ← **Settings** (בתפריט העליון).
2. בצד: **Secrets and variables** ← **Actions**.
3. לכל שורה בטבלה: **New repository secret** ← שם (בדיוק כמו בטבלה) ← ערך ← **Add secret**.

| שם | ערך |
|---|---|
| `TELEGRAM_BOT_TOKEN` | הטוקן מ-BotFather |
| `TELEGRAM_CHAT_ID` | בשלב 5 |
| `FINNHUB_API_KEY` | |
| `TIINGO_API_KEY` | |
| `FRED_API_KEY` | |
| `COINGECKO_API_KEY` | |
| `GEMINI_API_KEY` | |
| `SEC_CONTACT` | האימייל שלך. SEC דורשת אותו בכל בקשה. הוא לא נשמר בקוד. |
| `HEALTHCHECK_URL` | אופציונלי, שלב 7 |

### שלב 4: להעביר את הקוד לענף הראשי
GitHub מריץ משימות מתוזמנות **רק מהענף הראשי** (main). צריך למזג את ה-Pull Request של "חדר החדשות".

### שלב 5: לגלות את ה-chat_id
1. ב-repo: **Actions** ← בצד **newsroom** ← **Run workflow** ← בתיבה `task` בחר **whoami** ← **Run workflow**.
2. אחרי כחצי דקה, לחץ על ההרצה ← **run** ← פתח את השלב **Run**.
3. תופיע שורה `chat_id = 123456789`. שמור את המספר כסוד `TELEGRAM_CHAT_ID`.

### שלב 6: בדיקה והרצה ראשונה
1. **Run workflow** עם `probe`: תקבל בטלגרם רשימת ✅/❌ לכל מקור ומפתח.
2. **Run workflow** עם `morning`: מהדורת בוקר אמיתית, עכשיו.

### שלב 7 (מומלץ, לפני הנסיעה): התראה אם GitHub מפסיק להריץ
1. healthchecks.io ← **Sign Up** (חינמי).
2. **Add Check** ← Period: **1 hour**, Grace: **2 hours**.
3. **Integrations** ← **Telegram** ← לחבר.
4. להעתיק את כתובת ה-Ping (`https://hc-ping.com/...`) לסוד `HEALTHCHECK_URL`.

## ⚙️ שינוי הגדרות

| מה | איפה |
|---|---|
| רשימת המעקב | בבוט: `/add`, `/remove`, `/list`. או `config/watchlist.yaml` |
| שעת המהדורה, ימים | `config/settings.yaml` ← `editions.morning` |
| רגישות "תנועה חריגה" | `config/settings.yaml` ← `volatility.alert_sigma` (ברירת מחדל 2) |
| שעות שקט | `config/settings.yaml` ← `quiet_hours` |
| ספק / מודל שפה | `config/settings.yaml` ← `llm.provider`, `llm.models` (נוסים לפי הסדר) |
| בלי Yahoo כלל | `config/settings.yaml` ← `sources.yahoo_fallback: false` |
| פידי RSS | `config/sources.yaml` |
| סקטורים, קשרים (MAGS וכו'), ישיבות פד | `config/market.yaml` |

### פקודות הבוט
`/add TICKER` · `/remove TICKER` · `/list` · `/settings` · `/pause` (או `/pause 6h`, `/pause 2d`) · `/resume` · `/help`

הבוט עונה **רק ל-chat_id שלך**. פקודות נקלטות בהרצה הבאה (עד כשעה).

## 🧯 כשמשהו נשבר

| מה רואים | מה עושים |
|---|---|
| "⚠️ מקורות שלא ענו: X" | בדרך כלל זמני. אם חוזר כמה ימים: `probe` ולבדוק את המפתח של X. |
| "⚙️ מהדורת גיבוי (מודל השפה לא זמין)" | `probe` ← לבדוק את השורה "Gemini models". אם מודל הוצא משימוש, להחליף שם ב-`llm.models`. |
| "X משפטים נפסלו בבדיקת המספרים" | תקין. המודל כתב מספר שלא היה בנתונים, והמשפט נמחק. |
| "⚠️ המערכת נתקלה בתקלה" | ב-**Actions** ללחוץ על ההרצה האדומה. הסיבה כתובה בהודעה ובלוג. |
| לא הגיעה מהדורה בכלל | **Actions**: האם יש הרצות? אם לא, ייתכן שה-workflow הושבת: **newsroom** ← **Enable workflow**. |

## 💰 עלויות ומגבלות
- **GitHub Actions:** בשלב 1 כ-780 הרצות בחודש, כל אחת פחות מדקה. ב-repo פרטי המכסה היא 2,000 דקות. ברירת המחדל של מגבלת ההוצאה היא $0, כלומר **אף פעם לא תחויב**. בחריגה ההרצות פשוט נעצרות.
- **Finnhub:** 60 קריאות לדקה. מהדורת בוקר משתמשת בכ-60.
- **Tiingo:** 50 לשעה, 1,000 ביום. היסטוריה מתעדכנת פעם ביום לכל סימול.
- **Gemini:** קריאה אחת למהדורה. במסלול החינמי Google רשאית להשתמש בתוכן הבקשות. נשלחות רק כותרות ציבוריות וסימולים.

## 🔐 פרטיות
- נשמרים רק סימולים. אין כמויות, סכומים או שווי.
- כל המפתחות ב-GitHub Secrets. הקוד מוחק אותם מכל הודעת שגיאה לפני שהיא נכתבת ללוג או נשלחת.
- נשמרים רק כותרת, קישור, מקור ושעה של כל ידיעה, לא טקסט של כתבות. הארכיון נמחק אחרי 90 יום.
