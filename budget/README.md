## 5 לשוניות
| לשונית | תפקיד |
|---|---|
| 📊 תמונת מצב | הלוח הראשי. מציג אוטומטית את החודש האחרון שמולא (או כל חודש שבוחרים): 8 כרטיסי מדדים, תקציב מול בפועל, 5 ההוצאות הגדולות, תובנות אוטומטיות ו-3 גרפים |
| 📥 הזנה חודשית | המקום היחיד שמזינים בו: שורה לכל קטגוריה, עמודה לכל חודש. חריגה מהתקציב נצבעת באדום |
| 📈 מגמות | סיכום 12 חודשים, 4 גרפים ומפת חום של כל קטגוריות ההוצאה |
| 🎯 יעדים | התקדמות לכל תוכנית חיסכון וסילוק כל חוב, כולל כמה להפקיד בחודש ומתי החוב ייסגר |
| 📖 מדריך | 3 צעדים להתחלה ומקרא צבעים |
