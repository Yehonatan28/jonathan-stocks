# 💰 טבלת ניהול תקציב שנתי – Google Sheets

קובץ: [`budget.xlsx`](budget.xlsx) · נבנה ע"י [`build_budget.py`](build_budget.py)

## איך פותחים ב-Google Sheets
1. מורידים את `budget.xlsx`.
2. נכנסים ל-Google Drive ← **חדש** ← **העלאת קובץ**.
3. לוחצים פעמיים על הקובץ ← **פתיחה באמצעות Google Sheets** (או: קובץ ← שמירה כ-Google Sheets).
